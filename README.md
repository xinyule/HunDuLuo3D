# HunDuLuo3D

魂斗罗3D — 按 FC 版《魂斗罗》原作 8 关重制的真 3D 第三人称射击，镜头为 GTA 式人后越肩视角，基于 Three.js 构建。

## 这版重做了什么（相对旧版）

- **GTA 式镜头**：角色身后越肩镜头，鼠标可绕人转、可俯仰瞄高低，右键开镜收紧，镜头撞墙自动拉近，平滑阻尼跟随；不瞄准时角色朝跑动方向转身，开火时锁镜头方向横移扫射。
- **关卡按原作**：线性走廊推进（不再是方形竞技场清场），8 关顺序与场景严格按原作——丛林 / 基地1 / 瀑布 / 基地2 / 雪原 / 能量地带 / 仓库 / 异形巢穴；基地关保留原作「打感应器→落电网」机制，瀑布关向上攀爬，能量区火焰喷口按节拍封路，仓库有尖刺矿车，雪原有装甲扫讨车中 Boss。
- **Boss 每关不同**：防御壁（先塔后芯）、基地独眼核心、异形魔像（开口才可伤）、分幻鬼（四影对齐真身现形）、反重力飞碟（投放孢子）、巨型装甲兵（掷圆盘+跳砸）、最终闸门、龙神+异形心脏。
- **魂斗罗式战斗**：无限弹药无换弹；飞鹰徽章打下来换枪——M 机枪 / F 火球 / L 激光 / S 散射（招牌五发扇形）/ R 加速 / B 防护罩，阵亡掉回普通枪；敌人子弹是看得见的慢速红弹丸，能跳、能趴躲开（旧版是按距离掷骰子扣血）。
- **折中档伤害**：3 格血（子弹/近战/爆炸各 1 格），无自动回血，靠道具回血；每 10000 分 +1 命，复活回检查点并短暂无敌。
- **命数可选 + 原作彩蛋**：主菜单可选 3 / 5 / 10 / 30 / ∞ 条命；命尽可续关 3 次（本关重开、分数保留）；标题画面输 ↑↑↓↓←→←→BA 触发原作科乐美秘籍直接 30 命；最高分本地存档。
- **补齐的原作元素**：瀑布关喷火石像、仓库压顶机、丛林木桥过后坍塌、雪原降雪、过关奖励 1000 分、程序化 8-bit 风 BGM（M 键开关，非原作旋律复刻）。
- **修掉旧版两个致命 bug**：阵亡画面永不弹出（状态被提前改写导致软死）、击杀分数永远为 0（敌人生成时玩家引用为空）。新版状态只能由 Game 状态机改，角色/敌人只发事件回调。

## 操作

| 操作 | 键鼠 | 触屏 |
|------|------|------|
| 移动 | WASD（相对镜头） | 虚拟摇杆 |
| 镜头 | 鼠标（点击锁定指针） | 拖动屏幕 |
| 射击 | 鼠标左键 | 射击按钮 |
| 瞄准 | 鼠标右键（镜头收紧） | 射击时自动 |
| 跳跃 | 空格（翻跟头跳） | 跳按钮 |
| 趴下 | C / Ctrl（按住） | 趴按钮（点按切换） |
| 疾跑 | Shift | - |

## 运行

直接用浏览器打开 `index.html`，或启动本地服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术栈

- Three.js r157（本地文件，无构建工具、无外部依赖）
- Web Audio API 程序化音效（无音频文件）
- 模型全部代码拼装（无外部素材）
